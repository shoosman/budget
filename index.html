Пока пусто

Если вы уже вели бюджет на другом устройстве — нажмите «☁ Синхронизация» внизу и вставьте свой токен: данные подтянутся сами.
Если начинаете с нуля — создайте первый месяц кнопкой ниже.

Клик по стрелке слева от названия месяца сворачивает его — итоги останутся видны в шапке месяца. Строки можно перетаскивать за «⋮» — внутри списка и между половинами месяца. Через ✎ у строки: комментарий, пометка ★ «постоянный» и частичная оплата. «↶ отменить» (или Ctrl+Z) возвращает последнее действие — удаление, перетаскивание, правку. «Копия предыдущего» переносит все статьи и комментарии, но снимает галочки. Изменения сохраняются автоматически; «☁ Синхронизация» связывает телефон и компьютер через ваш GitHub.

☁ Синхронизация между устройствами

Данные будут храниться в вашем личном секретном гисте на GitHub — бесплатно и без ограничений по времени. Настройте один раз на каждом устройстве, дальше всё будет синхронизироваться само: при открытии страница забирает свежие данные, при изменениях — отправляет их в облако.

Как получить токен (один раз, ~5 минут)
  1. Зарегистрируйтесь или войдите на github.com.
  2. Откройте github.com/settings/tokens (Settings → Developer settings → Personal access tokens → Tokens (classic)).
  3. Нажмите Generate new token (classic).
  4. Note: напишите что угодно, например «бюджет». Expiration: No expiration.
  5. В списке галочек отметьте только gist — больше ничего.
  6. Нажмите Generate token внизу и скопируйте строку вида ghp_… — она показывается один раз.
  7. Вставьте её в поле выше и нажмите «Подключить». На втором устройстве вставьте этот же токен — приложение само найдёт ваши данные.

Токен даёт доступ только к гистам вашего аккаунта и хранится только в браузере на этом устройстве (в резервные копии не попадает). Гист секретный: в поиске и в вашем профиле его не видно, но это не шифрованное хранилище — не пишите в комментариях полные номера карт и счетов, достаточно последних 4 цифр.
