# Бюджет

Один репозиторий — три способа пользоваться одним и тем же приложением:

| Где | Как | Что делает GitHub |
|---|---|---|
| **Android** | APK из раздела **Releases** | Actions собирает и подписывает APK при каждом пуше |
| **macOS / Windows** | сайт `https://ВАШ-НИК.github.io/budget/`, установить из Chrome («Установить приложение») или Safari (Файл → «Добавить в Dock») | Pages раздаёт файлы из корня |
| **Любой браузер** | та же ссылка | — |

Данные между всеми тремя синхронизируются через ваш секретный GitHub Gist (кнопка «☁ Синхронизация» внутри приложения, тот же токен на каждом устройстве). В репозитории ваших цифр нет — только пустое приложение.

## Первый запуск (один раз)

1. **Создайте репозиторий** на github.com: «+» → New repository → имя `budget` → **Public** (бесплатный Pages работает только для публичных) → Create.
2. **Загрузите всё содержимое этой папки**, включая скрытую папку `.github` — проще всего так:
   - на компьютере в папке с файлами: `git init && git add -A && git commit -m init && git branch -M main && git remote add origin https://github.com/ВАШ-НИК/budget.git && git push -u origin main`
   - либо через веб: Add file → Upload files, перетащить всё (папку `.github/workflows/build.yml` и `android/…` веб-загрузчик примет, если перетаскивать папки целиком из Finder).
3. **Разрешите Actions писать в Releases**: Settings → Actions → General → внизу «Workflow permissions» → **Read and write permissions** → Save.
4. **Pages**: Settings → Pages → Source: Deploy from a branch → `main` / `/ (root)` → Save.

Через 3–5 минут:
- во вкладке **Actions** появится зелёная галочка, а в **Releases** (справа на главной странице репозитория) — `budget.apk`;
- ссылка на сайт появится в Settings → Pages.

## Установка APK на Samsung

1. На телефоне откройте страницу репозитория → **Releases** → скачайте `budget.apk`.
2. Откройте файл из уведомления или из «Мои файлы → Загрузки». Телефон спросит разрешение устанавливать из этого источника (Chrome / Мои файлы) — разрешите один раз.
3. Play Protect может предупредить «неизвестный разработчик» — это нормально для самодельного приложения, нажмите «Всё равно установить».
4. Запустите «Бюджет» → ☁ Синхронизация → вставьте токен.

## Обновления

Загрузили новый `index.html` в репозиторий (или любую правку) → через несколько минут в Releases лежит новый `budget.apk`. Скачайте и откройте — он ставится **поверх** старого как обновление, все данные остаются (ключ подписи один и тот же, он лежит в `android/keystore/`). Сайт на Pages обновится сам; если в приложении-сайте видите старую версию — поменяйте `VERSION` в `sw.js`.

## Структура

```
index.html, sw.js, manifest.webmanifest, *.png   — веб-приложение (Pages)
android/                                          — обёртка для APK (WebView)
android/keystore/budget.jks                       — ключ подписи (пароль budget123)
.github/workflows/build.yml                       — сборка APK в GitHub Actions
```

Внутри APK та же страница, что на сайте: Actions копирует файлы из корня в `android/app/src/main/assets` перед сборкой, так что править нужно только `index.html` в корне.
